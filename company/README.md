# 회사 본부 (HQ) — 임시 위치

이 디렉터리는 회사(상위 프로젝트)의 규정집·부서 정의·기록 대장이다.

**원래 위치는 별도 저장소 `hq`다.** 세션의 GitHub 연동에 저장소 생성 권한이
없어 임시로 제품 저장소(duty) 안에 두었다. 마스터가 `hq` 저장소를 만들면
사무국이 이 디렉터리 전체(+ `.claude/agents/`의 부서 정의 사본)를 이전한다.

## 마스터의 hq 저장소 생성 방법 (1분)
1. github.com 로그인 → 우측 상단 **+** → **New repository**
2. Repository name: `hq` / **Private** 선택 / "Add a README" 체크
3. **Create repository** 클릭 → 사무국에 "hq 만들었어"라고 알려주면 이전 진행

## 구성
- `regulations/00-헌장.md` … `08-수익화준비.md` — 회사 규정 제0~8장
- `ledger/lessons.md` — 교훈 대장 (재발 방지 규칙)
- `ledger/decisions.md` — 마스터 결정 기록부
- `research/` — 회사 구조 설계의 근거가 된 조사 보고서 4편
  (학술 / 실전 사례 / 실패·가드레일 / 중간관리자 검수·통합)

## 저장소 구조 원칙 (분리 이유)
- **hq(회사)**: 규정·기록·부서 정의 — 모든 제품에 공통
- **제품별 저장소(duty, 이후 신규 제품)**: 코드 + 그 제품의 CLAUDE.md
  (회사 규정 요약을 내장해 어떤 세션이든 규정을 따르게 함)
- 이유: ①제품마다 배포·CI 수명주기가 달라 커밋이 섞이면 불필요한 배포·CI가
  돈다 ②나중에 제품 저장소에 협력자를 초대해도 회사 내부 규정·기록은 노출되지
  않는다 ③새 제품을 시작할 때 hq 규정을 그대로 물려받는다.
