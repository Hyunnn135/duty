# 실제 근무표 전사 데이터 (61병동)

수간호사가 작성한 **실제 근무예정표 사진**(2026년 7·8월)을 셀 단위로 전사한 데이터입니다.
근무표 자동 생성기의 검증·테스트용 실사례로 사용합니다.

## 파일

| 파일 | 내용 |
|------|------|
| `roster_source.py` | 전사 원본 데이터 + 자동 검산 + CSV/JSON 생성기 |
| `schedule_2026_07.csv` | 7월 근무표 (25명 × 31일) |
| `schedule_2026_08.csv` | 8월 근무표 (23명 × 31일) |
| `schedule.json` | 두 달 통합 구조화 데이터(코드 설명·팀·집계 포함) |

재생성/검산: `python data/roster_source.py`

## 검증 방식

각 행 우측의 **집계값(D/E/N/M/S/S1/HY/PH/AH/OFF)** 을 셀 카운트와 대조해 자동 검산합니다.
전사 시 사진을 고해상도로 잘라 셀 단위로 읽고, 위 집계와 100% 일치함을 확인했습니다.
**7월 25명·8월 23명 전원 집계 일치**(파트장 행 제외).

## 근무 코드

| 코드 | 의미 |
|------|------|
| `D` / `E` / `N` / `M` | 데이(07-15) / 이브닝(15-22) / 나이트(22-07) / 미드 |
| `OFF` | 오프(휴무) |
| `S` / `S1` | 파트장 상근(관리자 근무) |
| `HY` | 연차 · `경조` 경조사 휴가 |
| `M/D` `M/E` | 초록 형광 표시 복합·수정 근무(집계 D/E/N/M엔 미포함) |
| `.` | 해당 월 근무 없음(전출 등) |

## 병동 구조 (사진에서 확인)

- **3개 팀** 운영 (굵은 가로선으로 구분): 7월 9/8/8명, 8월 9/6/8명
- 규모: 7월 25명, 8월 23명 (임지호·홍예준 7/13 71병동 전출)
- 팀 1행(김서연)은 **파트장**으로 D/E/N 스케줄링 대상이 아님

## 관찰된 인력 배치 (일자별 집계 행 기준, 8월)

- 평일 대략 **D5 / E5 / N4**, 주말 **D4 / E4 / N4** (+미드 M 간헐)
- WardConfig 기본값 산정의 실제 근거로 활용 가능

## 주의 / 한계

- **파트장(김서연) 행**은 관리자 상근 행으로 원본 집계 자체가 31일과 맞지 않아
  S/S1 표기가 근사치입니다. 검산에서 제외했으며 스케줄링에는 사용하지 않습니다.
- `M/D`·`M/E` 형광 셀은 원본에서 집계 D/E/N/M에 포함되지 않고 근무시간에만
  일부 반영되는 수기 표기로, 셀 값 그대로 보존했습니다.
