👥 간호사 명단 부서장 전용 · 위→아래 = 경력순 (드래그 또는 ▲▼로 순서 변경)

이름 왼쪽의 ⠿를 잡고 끌면 순서·팀을 바꿀 수 있습니다(다른 팀 표로도 이동 가능). 위에 있을수록 고참입니다. 트레이닝 중인 신규는 정원(4/4/4)에서 제외되고 교육자와 항상 같은 근무에 배정됩니다 (면담 F2). 단독근무: 트레이닝 직후 신규가 팀 듀티를 혼자 감당하지 못하면 "모두 불가"/"나이트만"으로 설정 — 불가한 교대에서는 반드시 단독 가능한 팀원이 같은 듀티에 함께 배정됩니다(하드 규칙).

📝 원티드 · 사전배정 · 전월 이월 선택

오프(O)는 최우선 반영. 같은 팀 오프 겹침은 가급적 피해 반영됩니다(불가피하면 허용). 연속 최대 3일.
🔄 발행된 전월 근무표의 마지막 7일이 자동으로 반영되어 월초 연속·회전 규칙에 적용됩니다 (발행된 전월 표가 없으면 이월 없이 생성). 별도 입력이 필요 없습니다.
여러 안: 동일 품질의 서로 다른 후보를 만들어 파트장이 선택합니다. (단일 유일해 수렴은 병동 규모상 비현실적 — docs/EXPERIMENT_REPORT.md)
아직 생성된 근무표가 없습니다. “설정” 탭에서 근무표를 생성하세요.

🙋 나의 원티드 신청

데이·이브닝·나이트 원티드는 반영되지 않을 수 있습니다. 원티드는 한 건당 최대 3일까지 신청할 수 있고, 같은 팀 오프 겹침은 가급적 피해서 반영됩니다(불가피하면 겹칠 수 있음). 이미 근무표가 발행된 달과 지난 달은 신청할 수 없습니다 — 변경이 필요하면 부서장에게 직접 문의하세요.
