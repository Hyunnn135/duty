## 1. 근무표 생성 엔진 관련

### 솔버 (Solver)
- **정의**: 복잡한 조건(제약)을 모두 만족하는 답을 자동으로 찾아주는 프로그램.
- **비유**: 스도쿠를 대신 풀어주는 기계. 규칙만 알려주면 빈칸을 알아서 채움.
- **우리 예**: 간호사·날짜·근무 규칙을 넣으면 근무표를 채워주는 `scheduler.py`.

### 제약조건 (Constraint)
- **정의**: 답이 반드시(또는 되도록) 지켜야 하는 조건.
- **하드 제약(hard)**: **절대** 어기면 안 되는 것. (예: 나이트 다음날 데이 금지)
- **소프트 제약(soft)**: 되도록 지키되, 불가피하면 어길 수 있는 것. (예: 개인 오프 희망)
- **우리 예**: "교대별 최소 인원"=하드, "나이트 공평 분배"=소프트.

### 목적함수 (Objective function)
- **정의**: 여러 답 중 '더 좋은 답'을 고르는 **점수 기준**. 보통 벌점(페널티)을 최소화.
- **비유**: 시험 채점 기준표. 소프트 제약을 어길 때마다 감점 → 감점 총합이 가장 작은 답 선택.
- **우리 예**: (희망 미반영 × 10) + (나이트 편차 × 3) 를 최소화.

### OR-Tools / CP-SAT
- **정의**: 구글이 만든 **제약조건 최적화 라이브러리**(솔버 모음). CP-SAT는 그 안의 강력한 솔버.
- **비유**: 우리가 직접 스도쿠 푸는 알고리즘을 안 짜도 되게 해주는, 검증된 '풀이 엔진'.
- **우리 예**: 근무표의 모든 규칙을 CP-SAT에 넘겨 최적 근무표를 계산.

### 회전 매트릭스 (Rotation matrix)
- **정의**: '전날 근무 → 다음날 근무' 전이가 허용인지 금지인지 적은 표.
- **우리 예**: N(나이트) → D(데이) = 금지, D → E = 허용. (§6.2)

## 2. 검증·테스트 관련

### 솔버 검증 (Verification)
- **정의**: 우리가 만든 규칙/코드가 **실제와 맞는지 확인**하는 작업.
- **우리 예**: 실제 7·8월 근무표에 우리 규칙을 돌려, 위반이 몇 건 나오는지 세어봄
  (`data/verify_rules.py`). 위반 0건이면 그 규칙은 현실과 일치.

### 검산 / 체크섬 (Checksum)
- **정의**: 데이터가 맞는지 **다른 방법으로 한 번 더 대조**해 오류를 잡는 것.
- **비유**: 영수증 항목을 더한 값이 합계와 같은지 확인하는 것.
- **우리 예**: 근무표 셀을 하나씩 읽은 뒤, 각 줄의 D/E/N 개수를 세어 표에 인쇄된
  집계 숫자와 같은지 대조 → 전사 오류를 자동으로 잡음.

### 테스트 픽스처 (Test fixture)
- **정의**: 자동 테스트에 쓰려고 **미리 준비해 둔 고정 데이터**.
- **비유**: 요리 실습 전에 미리 계량해 둔 재료. 매번 똑같이 쓸 수 있음.
- **우리 예**: 실제 61병동 근무표(`schedule_2026_07.csv`)를 '정답지'로 삼아,
  코드를 고칠 때마다 규칙을 자동 검사.

### 슬라이딩 윈도우 (Sliding window)
- **정의**: 연속된 구간을 한 칸씩 밀며 반복 검사하는 방법.
- **비유**: 7칸짜리 창틀을 1일씩 옮기며 "이 7일 동안 오프가 2번 있나?"를 매번 확인.
- **우리 예**: "어떤 7일을 봐도 근무 6일 이하"를 검사할 때 사용.

## 3. 데이터·웹 관련

### CSV / JSON
- **CSV**: 쉼표로 칸을 나눈 표 형식 텍스트. 엑셀로 바로 열림. (표 데이터에 적합)
- **JSON**: 이름:값 구조로 계층 데이터를 담는 형식. (프로그램끼리 주고받기 좋음)
- **우리 예**: 근무표를 사람이 보기 좋은 CSV와, 프로그램이 쓰기 좋은 JSON 둘 다로 저장.

### API / FastAPI
- **API**: 프로그램끼리 요청·응답을 주고받는 **약속된 창구**.
- **FastAPI**: 파이썬으로 API 서버를 쉽게 만드는 도구.
- **우리 예**: 웹 화면이 "이 조건으로 근무표 만들어줘"를 API로 요청 → 서버가 결과 반환.

### Pydantic
- **정의**: 입력 데이터의 **형식·규칙을 자동 검사**해주는 파이썬 도구.
- **비유**: 서류 접수처에서 빈칸·형식 오류를 미리 걸러주는 직원.
- **우리 예**: "간호사 id 중복 금지", "일수는 1~62" 같은 검사를 자동 수행(`models.py`).

## 4. 근무표 도메인 용어 (병동 실무)

- **D / E / N / M**: 데이(07-15) / 이브닝(15-22) / 나이트(22-07) / 미드.
- **OFF**: 오프(휴무). **HY**: 연차. **경조**: 경조사 휴가. **S/S1**: 파트장 상근.
- **나이트 keep**: 나이트 후 오프를 붙여 회복을 보장하는 관행.
- **역회전**: E→D, N→D 처럼 휴식이 짧아지는 나쁜 근무 전환.
- **풍당풍당**: 근무가 하루씩 흩어져(고립) 배치되는 것. 지양 대상.
- **듀티(duty)**: 근무(표). '듀티표' = 근무표.
