# 사용 설명서 — 간호사 근무표 자동 생성

이 문서는 **파트장(관리자)**, **부서원**, **마스터** 각 역할이 웹앱을 실제로 쓰는 방법을
단계별로 설명합니다. 처음 쓰시는 분도 순서대로 따라 하면 됩니다.

---

## 0. 로그인 · 역할

앱에 접속하면 로그인 창이 뜹니다. 처음이면 **"회원가입"** 을 눌러 이메일·비밀번호·이름·
병동(예: `61`)을 입력합니다.

- **가장 먼저 가입한 사람이 자동으로 "마스터"** 가 됩니다(최고 관리자).
- 이후 가입자는 모두 **부서원**으로 시작합니다. 파트장 권한이 필요하면 마스터가
  역할을 올려줍니다(아래 3-B).

| 역할 | 할 수 있는 일 | 보이는 탭 |
|------|--------------|-----------|
| **마스터** | 모든 것 + 역할 관리 + 피드백 수신함 | 설정·근무표·신청관리·통계·수신함 |
| **파트장(관리자)** | 명단·근무표 생성·발행·원티드 승인 | 설정·근무표·신청관리·통계 |
| **부서원** | 원티드 신청·내 근무/통계 조회 | 근무표·원티드 신청·내 통계 |

---

## 1. 파트장(관리자) — 근무표 만들기

### 1-A. 명단 입력 (한 번만, 이후 수정)

**설정 탭 → 👥 간호사 명단**

1. 표에 간호사를 입력합니다. **명단 순서 = 경력순**(위가 고참).
   - **팀**: 1/2/3
   - **경력순위**: 팀 안에서의 순위(1이 최고참)
   - **나이트**: 야간 근무 가능 여부(임신·산후 등은 체크 해제)
   - **트레이닝**: 입사 첫 달 교육 대상이면 체크(정원에서 빠지고 교육자와 같은 근무)
   - **교육자**: 트레이닝인 경우 따라다닐 선배 선택
2. **"명단 저장"** 을 누르면 서버에 저장됩니다. 다음에 접속해도 유지됩니다.

### 1-B. 편성 조건 확인

**설정 탭 → 📅 편성 기간 & 인원 기준**

- **연도·월**: 만들 달
- **Day/Evening/Night 최소·적정 인원**: 기본값 4/4/4
- **공휴일**: 쉼표로 날짜 입력. **대체공휴일도 꼭 포함**하세요.
  - 예: 2026년 8월은 광복절(15) + 대체공휴일(17) → `15,17`
- 월 오프 수는 (토+일+공휴일) 수에 맞춰 자동 계산됩니다.

### 1-C. 운영 모드 (핵심)

**설정 탭 → 🎯 운영 모드** — 기본으로 켜져 있습니다(권장).

- 켜면 매일 인원이 **D4·E4·N4·M1(액팅 있는 날)** 또는 **D5·E5·N4(액팅 없는 날)**
  중 하나로 **정확히** 맞춰집니다(초과·미달 불가).
- **액팅(미드) 근무 일수**: 한 달에 액팅을 넣을 날 수(기본 8).
  - 액팅을 늘리면 오프 12개인 인원이 늘고, 줄이면 오프 11개인 인원이 늘어납니다
    (액팅 1일 = 오프 12명 1명 증가). 병동 상황에 맞게 조절하세요.
- 나이트 균등·오프 11~12 균등·원티드 100% 우선이 자동으로 함께 적용됩니다.

### 1-D. 원티드 · 사전배정 · 전월 이월 (선택)

**설정 탭 → 📝 원티드 · 사전배정 · 전월 이월**

- **원티드 신청**: 한 줄에 하나. `이름, 시작일, 종료일, 종류(O/D/E/N)`
  - 하루만이면 종료일 생략 가능: `김민지, 3, O` (3일 오프)
  - 종류 생략 시 오프(O)로 간주: `김민지, 3, 5` (3~5일 오프)
  - 오프(O)는 최우선 반영, 같은 팀 오프는 같은 날 겹칠 수 없습니다.
- **사전 확정 휴무(연차 등)**: `이름, 날짜, 코드(HY/공가/병가/Edu/경조/PH/AH)`
- **전월 말일 이월**: `이름, 근무나열(오래된→마지막)` — 예: `정하은, N,N,O`
  - 전월 마지막 7일 정도를 넣으면 월초 연속·회전 규칙에 반영됩니다.

> 부서원이 웹으로 신청한 원티드는 "신청관리"에서 승인하면 자동 반영됩니다(2-B). 위 칸은
> 파트장이 직접 넣을 때 씁니다.

### 1-E. 생성

**설정 탭 하단 → "근무표 생성"**

- 운영 모드에서는 최고 품질 계산을 위해 **약 1~2분** 걸립니다. 창을 닫지 마세요.
- 완료되면 자동으로 **근무표 탭**으로 넘어갑니다.
- **"여러 안 생성(3)"**: 같은 품질의 서로 다른 후보를 3개 만들어 고를 수 있습니다.

### 1-F. 검토 · 수정 · 발행

**근무표 탭**

- 달력형 표에서 요일·주말 음영·팀 구분·교대별 합계(Σ)·개인 카운트를 확인합니다.
- 셀을 직접 고치면 **대원칙 위반을 자동 검사**해 경고합니다. 위반 시 **"대안 3안 보기"** 로
  최소 수정안을 받을 수 있습니다.
- CSV·엑셀·PNG로 내보낼 수 있습니다.
- **"📢 발행"** 을 누르면 병동 구성원 모두가 자기 근무를 조회할 수 있습니다.

---

## 2. 파트장 — 원티드 신청 관리

**신청관리 탭**

### 2-A. 신청 기간 설정
- 부서원이 원티드를 낼 수 있는 **여는 시각·닫는 시각**을 정하고 **"기간 저장"**.
- 기간이 지나면 부서원 화면에 만료 문구가 뜨고 신청이 막힙니다.

### 2-B. 신청 승인/반려
- 부서원이 낸 원티드 목록이 보입니다. **승인**하면 다음 생성 때 반영, **반려**도 가능.
- (이메일이 설정된 경우) 승인·반려 결과가 신청자에게 메일로 전달됩니다.

---

## 3. 부서원 — 원티드 신청 · 내 근무 조회

### 3-A. 계정 연결 (처음 한 번)
로그인 후 "명단 미연결"이 보이면, **파트장에게 내 계정을 명단의 내 이름에 연결해 달라고
요청**하세요(파트장이 설정 탭 명단의 "계정" 칸에서 연결). 연결되면 "내 근무/내 통계"가
내 이름 기준으로 동작합니다.

### 3-B. 원티드 신청
**원티드 신청 탭** — 신청 기간 안에서 원하는 오프/근무 날짜를 제출합니다.

### 3-C. 내 근무 · 통계
- **근무표 탭**: "내 근무만" 체크로 내 근무만 볼 수 있습니다.
- **내 통계 탭**: 내 D/E/N/오프 집계·나이트 분포를 봅니다(본인 것만 보임).

### 3-D. 피드백
근무표에 대한 의견을 보내면 **마스터 수신함**으로 전달됩니다.

---

## 4. 마스터 전용

- **역할 관리**: 부서원을 파트장으로 올리거나 내릴 수 있습니다.
- **📨 수신함**: 부서원 피드백을 모아 봅니다.

## 5. 용어 사전

| 용어 | 뜻 |
|------|-----|
| **D / E / N / M / O** | 데이 / 이브닝 / 나이트 / 액팅(미드) / 오프 |
| **원티드(Wanted)** | 부서원이 미리 신청하는 희망 오프·근무 |
| **대원칙** | 반드시 지켜야 하는 규칙(나이트 후 휴식, 하루 1근무, 연속근무 ≤5 등) |
| **운영 모드** | 61병동 확정 인원 규칙을 정확히 적용하는 생성 모드 |
| **액팅(미드)** | 낮 피크를 돕는 중간 근무. 넣는 날 수를 조절 가능 |
| **발행** | 완성한 근무표를 병동 구성원이 볼 수 있게 공개하는 것 |

## 6. 자주 묻는 질문

**Q. 왜 어떤 사람은 오프가 11개, 어떤 사람은 12개인가요?**
22명·31일·정확 인원 규칙에서는 전원 오프 11이 산술적으로 불가능합니다. 가장 공정한
분포가 11개 일부 + 12개 일부이며, 12개인 사람은 하루 더 쉬는 것이라 손해가 아닙니다.
액팅 일수를 바꾸면 이 비율이 달라집니다(운영 모드 참고).

**Q. 첫 접속 때 8~10초 멈춰요.**
비용 절감을 위해 안 쓸 때 서버를 꺼두기 때문입니다(scale-to-zero). 첫 요청 시 켜지는
시간이며, 이후엔 빠릅니다. 항상 즉시 응답이 필요하면 관리자에게 문의하세요.

**Q. 컴퓨터를 바꿔도 되나요?**
됩니다. 모든 데이터는 서버(클라우드)에 있어, 어느 기기서든 **같은 계정으로 로그인**하면
이어서 쓸 수 있습니다.

**Q. 근무표가 실제 작년/지난달과 똑같이 나오지 않아요.**
같은 조건에서도 품질이 동일한 다른 배치가 여러 개 존재합니다("여러 안 생성"으로 비교
가능). 대원칙과 원티드를 모두 지키는 한, 여러 정답 중 하나가 나옵니다.
