## 1. 조사 방법

웹 검색 5회(한국어·영어)로 다음 영역을 조사: 정부 가이드라인/법령, 국제 학술 표준
(INRC: International Nurse Rostering Competition), 교대근무 인간공학, 국내 언론·노조
자료(나쁜 근무 패턴), 국내 듀티 앱 시장. 조사한 규칙 후보는 **전부 실제 61병동 7·8월
근무표에 대조**해 채택 여부를 결정했다(추측이 아니라 데이터로 판정).

## 2. 조사 결과 요약

### 2.1 법령·정부 가이드라인 (가장 중요한 수확)

**보건복지부 「간호인력 야간근무 가이드라인」** (2019.10 제정 → 2023.10 개정)
| 기준 | 내용 | 우리 계획과의 관계 |
|------|------|--------------------|
| 야간근무 시간 | 8시간 원칙 | 우리 N(22–07) 구조와 부합 |
| **연속 야간** | **3일 이하** | **T8(연속 나이트≤3)과 정확히 일치** — 실측으로 정한 값에 공식 근거 확보 |
| **야간 후 휴식** | **2일 이상 연속 야간 후 48시간 이상 휴식** | "나이트 후 오프 2개(N keep)"의 공식 근거. N-OFF-D 금지(P1)가 왜 타당한지도 설명 |
| 야간전담 | 월 야간 14일(제정)→**15일(개정)** 이내 | T10 파라미터의 공식 기준 (블로그의 '월 15개'와 일치) |

**근로기준법**
- **§70**: 임산부(임신 중 + 산후 1년 미만) **야간(22:00–06:00) 근로 원칙 금지**.
  예외는 본인 동의(산후 1년 미만) 또는 명시적 청구(임신 중) + 고용노동부장관 인가.
- **§71**: 산후 1년 미만 연장근로 제한(1일 2h·주 6h·연 150h).
- → T12가 "법조문 수준"으로 확정. 단 예외 절차가 존재하므로 병동이 전면 제외로
  운영하는지 확인 필요(면담 D5 신설).

### 2.2 학술 표준 — INRC(국제 간호사 근무표 대회) 제약 체계

세계 표준 제약 구성이 우리 설계와 거의 동형임을 확인:
- **하드**: 하루 1배정(=P2) · 최소 인원 · 합법 전이 매트릭스(=우리 회전 매트릭스 6.2) · 스킬 매칭
- **소프트**: 적정(optimal) 인원 부족 감점 · 연속근무 min/max · 연속오프 min/max ·
  주말 통짜(complete weekend) · 개인 선호 · **월 경계(border) 처리** — 우리 '전월 이월'과 동일 개념
- CP-SAT가 유전알고리즘 대비 **약 225배 빠르다**는 실험 보고 → 우리 기술 선택(OR-Tools CP-SAT) 타당성 확인.

### 2.3 인간공학·보건

- **전방(시계방향) 순환 D→E→N**이 생체리듬 적응에 유리, 역방향은 짧은 휴식(최소 8h)으로
  수면장애·우울 위험 — **P3(E→D 금지)·순방향 선호의 과학적 근거**.
- 언론·노조 자료의 대표 '헬 듀티' 3종: **나오데(N-O-D)·이브데이(E→D)·더블듀티(1일 2근무)**
  → 각각 P1·P3·P2로 **이미 전부 대원칙에서 커버**. 우리 대원칙 선정이 현장 문제의식과 정확히 일치.
- 단체협약 관행: 확정 근무표(번표) 변경 금지, 야간근무 후 수면휴가 등 → 면담 I4 신설.

### 2.4 시장 (국내 듀티 앱)

- 듀티메이트(dutymate.net)·하루듀티·듀팅·쓰리오프 등 다수 존재.
- ⚠️ **시안 가칭 '듀티메이트'가 실존 서비스(dutymate.net)와 동일** → 혼동·상표 문제
  방지를 위해 시안 명칭을 **'듀티원(가칭)'**으로 변경. 최종 이름은 사용자가 결정.

## 3. 실측 대조 — 새 후보 규칙 판정

조사에서 나온 후보를 실제 7·8월 표에 돌린 결과:

| 후보 규칙 | 실측 결과 | 판정 |
|-----------|-----------|------|
| 단일 나이트 금지(N 블록 ≥2) | 단일 N **0건** (나이트는 항상 2연속 이상) | ✅ **하드 채택 → T6a 신설** |
| 연속 2+N 후 오프 2개(48h) | 8월 **100% 준수**, 7월 예외 6건 | ⚠️ **준하드** — 면담 C3로 최종 확정 |
| 고립 오프 방지(연속 오프 ≥2, INRC) | 고립 오프 67건/44건 — **매우 흔함** | ❌ **비채택** (우리 병동 관행 아님) |
| 주말 통짜 오프(complete weekend) | 완전 주말 휴식 16~21%로 드묾 | ⚠️ 약한 소프트 후보 — 면담 E3 확장 |
| 최소 vs 적정 인원 이원화(INRC S1) | (구조 설계 사항) | ✅ **채택** — WardConfig에 반영 |

## 4. 분류 정리

### ① 계획에 추가한 것 (완료)
1. **T6 세분화**: T6a "나이트 블록 ≥2" **하드**(실측 0건 근거) / T6b "D·E 블록 ≥2" 강한 소프트.
2. **T7 강화**: 복지부 48시간 휴식 근거 명시, "연속 2+N 후 오프 2개"를 준하드로 승격 대기(C3).
3. **T8·T10·T12에 공식 근거 부착**: 복지부 가이드라인(연속 3일·전담 15일), 근로기준법 §70/71.
4. **적정(목표) 인원 개념**: 최소(하드)와 별도로 목표 인원 부족 감점(5.2 WardConfig).
5. **§4.5 외부 근거 조사 섹션** 신설(출처와 함께 영구 기록).
6. **시안 명칭 변경**: 듀티메이트 → 듀티원(가칭).

### ② 추가할 필요 없다고 판단한 것 (이유 포함)
| 항목 | 이유 |
|------|------|
| 고립 오프 방지(연속 오프≥2) | 실측상 고립 오프가 월 44~67건으로 일상 — 우리 병동 관행과 상반 |
| 더블듀티·이브데이·나오데 금지 | **이미 P2·P3·P1로 커버** — 중복 규칙 불필요 |
| 유전알고리즘·양자어닐링 등 대체 솔버 | CP-SAT가 실험상 압도적으로 빠르고 우리 규모(24명×31일)에 충분 |
| 12시간 2교대 등 타 교대제 | 우리 병동은 8시간 3교대+미드로 확정 |
| 야간근무 모니터링 의무 제출 | 기관 행정 영역 — 프로그램 범위 밖 (추후 리포트 기능으로 지원 가능) |
| 수면휴가 제도화 | 병원 인사제도 영역 — 근무표 생성기가 결정할 수 없음 (면담 I4에서 존재만 확인) |

### ③ 부서장(파트장)에게 새로 확인할 것 (질문지 반영 완료)
| 신설/보강 질문 | 내용 |
|----------------|------|
| **C3 보강** | 48시간 휴식(오프 2개)을 절대 규칙으로 볼지 — 7월 예외 6건의 성격 |
| **B5 신설** | 최소 인원과 별도의 '적정 인원'이 실무에 존재하는지 |
| **E3 보강** | 주말 통짜 오프 선호 여부 (실측 16~21%가 의도인지 불가피인지) |
| **D2 보강** | 야간전담 월 15일(복지부 개정) 적용 여부 |
| **D5 신설** | 임산부 야간 — 전면 제외인지, 법정 예외(동의+인가)를 실제 쓰는지 |
| **I4 신설** | 확정 근무표 변경(번표 변경) 절차·기록, 단체협약 보호조항 존재 여부 |
