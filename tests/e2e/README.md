# 실브라우저 E2E (Playwright) — 백업 내려받기

자동 테스트(pytest)는 HTTP·DB 수준까지만 본다. **화면에서 실제로 눌러야만 드러나는
결함**(중복 클릭, 모달 흐름, 배너 노출, 권한별 DOM 노출)은 여기서 잡는다.
검수부 지적대로 저장소에 하니스가 없어 높음 결함 3건이 이 사각지대에서 나왔다.

## 한 줄 실행

```bash
bash tests/e2e/run_backup_e2e.sh
```

임시 폴더에 새 DB를 만들어 서버를 띄우고, Chromium으로 화면을 조작하고, 스크린샷을
남긴 뒤 서버를 내린다. 저장소 데이터·운영 DB는 건드리지 않는다.
종료 코드 `0`이면 전 항목 통과(`1`=검증 실패, `2`=서버 기동 실패).

### 이 컨테이너에서 (교훈 L-8)

시스템 파이썬은 `cryptography`가 깨져 있으므로 venv 인터프리터를 넘긴다.
Chromium은 이미 설치돼 있다(`npx playwright install` 은 프록시가 막으므로 실행 금지).

```bash
PY=/경로/venv/bin/python bash tests/e2e/run_backup_e2e.sh
```

| 환경 변수 | 뜻 | 기본값 |
|---|---|---|
| `PY` | 파이썬 실행기 | `python3` |
| `E2E_PORT` | 서버 포트 | `8861` |
| `E2E_OUT` | 스크린샷 폴더 | 임시 폴더 `/shots` |
| `PLAYWRIGHT_BROWSERS_PATH` | 브라우저 위치 | `/opt/pw-browsers` |
| `PLAYWRIGHT_MODULE` | playwright 모듈 경로 | `/opt/node22/lib/node_modules/playwright` |

권한 코드는 **실행할 때마다 새로 생성**해 서버와 브라우저에 함께 넘긴다 —
저장소에 실값을 남기지 않는다.
